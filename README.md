# 台股個股診斷公開版

這是無持倉、無帳戶、無成本資料的 Streamlit 個股診斷網站。使用者可輸入股票代號、完整名稱或部分名稱。系統會下載公開歷史價格、成交量與 P/E，計算估值溫度、正常 P/E 參考價格、市場隱含成長壓力或獲利緩衝，以及短中長趨勢、動能、型態、量價與波動風險。

## 本機執行

```powershell
py -3 -m pip install -r requirements.txt
py -3 -m streamlit run quick_app.py --server.port 8502
```

## 雲端部署

將本資料夾單獨建立為 Git repository，部署入口指定為 `quick_app.py`。若使用 FinMind Token，請在部署平台的祕密環境變數中設定 `FINMIND_TOKEN`，不要寫入程式或上傳到 Git。

網站執行期間只會在 `data/quick_analysis.db` 建立公開市場資料快取；此資料庫不含個人持倉資料，且已由 `.gitignore` 排除。

公開測試時，請在 Streamlit App settings → Secrets 設定：

```toml
APP_PASSWORD = "自行設定的測試密碼"
```

密碼只存放在 Streamlit Secrets，不應提交到 GitHub。

- 六構面權重為趨勢20、動能20、量價15、相對0050強弱15、結構20、型態10。成交量或同期基準不足時不提供總分，不將缺漏當作零分。
- 雙低辨識採收盤價左右各3日確認，間隔至少7日、低點價差不超過12%、中間反彈至少3%，第二低點之前60日需曾回落至少10%。這些為待驗證規則，非統計成功率。
- 本次結構的確認價與失敗價固定；失敗或60個交易日後到期，同一第二低點不重啟。突破確認須收盤高於確認價、量比至少1.2及TRS至少70。
- 圖表標示結構發生／可用日期、歷史階段與固定價位；增加近5個交易日構面及證據變化。
- 歷史為目前資料逐日重算，不是當時保存的實盤紀錄；尚未完成含交易成本的策略回測。
- 行情仍未還原除權息與分割；近60日價格或0050出現單日超過25%斷點時暫停相關評分。較小公司行動不一定能攔截，仍需核對。
- 機會—風險矩陣不再把隱含EPS當成財報品質證明，也不將缺少PE解讀為轉機或上漲空間。

## 使用限制

### 可選成交密集參考區

K線上方可切換均線、反折價位、波段標記與成交密集參考區。成交區預設關閉，開啟後可選60／120交易日，以及主要區域或完整橫向分布。此功能不參與TRS計分。

成交分布是日線估算：每日成交量按高低價區間的重疊長度均勻分配至32個等寬價帶；全期同價時只有一帶。POC為最大量價帶，主要區域從POC逐次納入較大量的相鄰價帶至至少70%估算量；同量優先低價帶。區域展示本次全期間統計，不表示歷史上當時已知的支撐。

不足完整期間、缺高低價／量或超過25%單日斷點時不估算。未自動還原公司行動，較小斷點仍需核對。這不是實際逐價成交量、主力成本或未售出庫存，不保證支撐／壓力有效。

- 資料來源為公開市場資料；公開營運前仍須確認來源的使用條款、額度及轉載規定。
- 免費雲端環境的本機快取可能在重新啟動後消失，這不影響個人資料，僅會重新抓取市場資料。
- 本工具為歷史比較與市場期待診斷，不構成投資建議。
